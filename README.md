## Sobre mim

Sou aluno de Ciência da Computação na PUC Minas e gosto muito de back-end, principalmente da parte que o usuário nunca vê: quem pode acessar o quê, o que acontece quando uma regra de negócio é quebrada e como manter os dados consistentes.

Hoje estou tentando juntar isso com IA, colocando modelos dentro de aplicações que já têm usuários, regras e dados de verdade.
